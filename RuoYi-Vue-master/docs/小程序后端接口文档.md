## 二、通用说明

### 2.1 请求头

除登录接口外，所有请求必须携带以下请求头：

```
Authorization: Bearer {token}
Content-Type: application/json
```

### 2.2 统一响应格式

所有接口均返回以下 JSON 结构：

```json
{
  "code": 200,          // 状态码，200=成功，其他=失败
  "msg": "操作成功",      // 提示信息
  "rows": [],           // 数据列表（分页列表接口）
  "total": 0,           // 总记录数（分页列表接口）
  "data": {}            // 单条数据（详情接口）
}
```

**常见错误码：**

| code | 说明 |
|------|------|
| 200 | 成功 |
| 401 | 未登录或 token 过期，需重新登录 |
| 403 | 无权限访问 |
| 500 | 服务器内部错误 |

### 2.3 分页参数

列表接口支持以下分页参数（通过 URL query 传递）：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| pageNum | int | 1 | 页码 |
| pageSize | int | 10 | 每页条数 |

### 2.4 文件上传

使用 `multipart/form-data` 格式：

```
POST /common/upload
Content-Type: multipart/form-data

参数: file (binary) — 文件二进制数据
```

返回：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "url": "https://your-domain.com/profile/2026/04/22/xxx.jpg"
  }
}
```

#### PUT /zw/workOrder/accept/{id} — 接单

工程师接受工单，工单状态从 `0（待接单）`变为 `1（处理中）`。

**请求：**
```
PUT /zw/workOrder/accept/1
Authorization: Bearer {token}
```

**响应：**
```json
{ "code": 200, "msg": "接单成功" }
```

---

#### PUT /zw/workOrder/reject/{id} — 拒单

工程师拒单，工单状态不变（仍为待接单，可重新派发给其他工程师）。

**请求：**
```
PUT /zw/workOrder/reject/1
Content-Type: application/json

{
  "reason": "当前距离太远，无法及时上门"
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| reason | string | 是 | 拒单原因 |

**响应：**
```json
{ "code": 200, "msg": "已拒单" }
```

工程师到达现场后点击"开始处理"，工单状态从 `1（处理中）`变为 `2（待确认）`。

**请求：**

```
PUT /zw/workOrder/start/1
Authorization: Bearer {token}
```

**响应：**
```json
{ "code": 200, "msg": "已开始处理" }
```

#### PUT /zw/workOrder/complete/{id} — 完工确认

工程师完成维修后提交完工确认，工单状态从 `2（待确认）`变为 `3（已完成）`。

**请求：**
```
PUT /zw/workOrder/complete/1
Content-Type: application/json
Authorization: Bearer {token}

{
  "resultDesc": "已更换网络模块，打印机恢复正常连接",
  "signImage": "https://your-domain.com/sign/xxx.png",
  "photos": [
    "https://your-domain.com/photo/1.jpg",
    "https://your-domain.com/photo/2.jpg"
  ],
  "parts": "[{\"name\":\"网络模块\",\"quantity\":1}]",
  "nextVisitTime": "2026-07-22"
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| resultDesc | string | 是 | 维修结果描述（限500字） |
| signImage | string | 否 | 甲方签名图片 URL |
| photos | string[] | 否 | 完工照片 URL 数组 |
| parts | string | 否 | 更换配件 JSON 字符串 `[{"name":"配件名","quantity":1}]` |
| nextVisitTime | string | 否 | 建议下次巡检时间，格式 `yyyy-MM-dd` |

**响应：**
```json
{ "code": 200, "msg": "完工确认成功" }
```

| assetId | long | 是 | 资产ID |
| faultType | string | 是 | 故障类型，见下方枚举 |
| faultDesc | string | 是 | 故障描述（限500字） |
| faultPhotos | string[] | 否 | 故障照片URL数组，最多5张 |
| severity | string | 是 | 紧急程度：`urgent`=紧急，`normal`=一般 |

**故障类型（faultType）枚举：**

| faultType | 说明 |
|-----------|------|
| power_off | 无法开机 |
| runtime_error | 运行异常 |
| output_error | 输出异常 |
| net_error | 网络问题 |
| other | 其他 |

**响应：**
```json
{ "code": 200, "msg": "故障上报成功" }
```
