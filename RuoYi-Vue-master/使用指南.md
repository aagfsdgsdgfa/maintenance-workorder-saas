## 1. 系统简介

智维云服是一套设备运维管理系统，帮助企业管理设备资产、派发工单、安排巡检、记录故障、客户报修和满意度评价。

### 系统角色

| 角色 | 说明 |
|------|------|
| **管理员** | 拥有全部权限，可管理所有模块 |
| **客服/调度** | 负责受理报修、创建工单、派单给工程师 |
| **工程师** | 接收工单、执行巡检、现场打卡、提交结果 |
| **客户** | 通过客户门户查看自己的工单和资产，提交报修 |

### 业务总览

```
客户报修 ──→ 客服受理 ──→ 创建工单 ──→ 派单给工程师
                                            ↓
                          ┌──────────┬──────┴──────┬──────────┐
                          ↓          ↓             ↓          ↓
                       巡检任务   维修工单     送货工单    混合工单
                          ↓          ↓             ↓          ↓
                       现场打卡   故障处理     签收确认    完成确认
                          ↓          ↓             ↓          ↓
                       提交结果   提交结果     提交结果    提交结果
                          └──────────┴─────────────┴──────────┘
                                            ↓
                                      客户评价
```

### 2.3 通用操作

**表格操作**：
- 点击表头可排序
- 点击「刷新」按钮重新加载数据
- 输入关键字搜索，按回车搜索

**新增/编辑**：
- 点击「新增」按钮打开表单
- 填写完毕后点击「确定」保存
- 点击「取消」放弃操作

**删除**：
- 勾选要删除的记录，点击「删除」
- 系统会弹出确认框，确认后删除

## 4. 资产设备管理

管理所有设备资产，是系统的基础数据。

### 4.1 查看资产列表

入口：**资产设备** → **资产列表**

页面显示所有资产，可按以下条件筛选：
- 资产名称 / 资产编码
- 资产类型（服务器、网络设备、存储设备等）
- 资产状态（正常、故障、维修中、已报废）
- 所属客户

### 4.2 新增资产

1. 点击「新增」按钮
2. 填写资产信息：
   - **资产编码**：必填，唯一标识（如 AS202604001）
   - **资产名称**：必填，设备名称
   - **资产类型**：选择设备类型
   - **所属客户**：选择资产归属的客户
   - **存放位置**：设备存放的具体位置
   - **购买日期**：设备购入时间
   - **保修截止**：设备保修到期时间
   - **品牌/型号**：设备品牌和型号
3. 点击「确定」保存

### 4.3 编辑资产

1. 在资产列表中找到要修改的资产
2. 点击操作列的「编辑」按钮
3. 修改信息后点击「确定」

### 4.4 资产状态说明

| 状态 | 含义 |
|------|------|
| 正常 | 设备运行正常，无需处理 |
| 故障 | 设备出现故障，需要维修 |
| 维修中 | 正在维修中，暂不可用 |
| 已报废 | 设备已报废，不再使用 |

### 4.5 扫码查询

点击「扫码」按钮，用设备二维码扫码，快速定位到该资产。

## 5. 工单管理

工单是系统核心业务，贯穿整个运维流程。

### 5.1 工单状态说明

工单有5种状态，流转如下：

```
待接单 → 处理中 → 待确认 → 已完成
                        ↘ 已取消
```

| 状态 | 含义 | 谁能操作 |
|------|------|---------|
| 待接单 | 工单已创建，等待工程师接单 | 客服/工程师 |
| 处理中 | 工程师已开始处理 | 工程师 |
| 待确认 | 工程师已完成，等待客户确认 | 客户 |
| 已完成 | 客户已确认完成 | — |
| 已取消 | 工单取消 | 客服/管理员 |

### 5.2 创建工单

1. 点击「新增」按钮
2. 填写工单信息：
   - **工单标题**：简述工单内容
   - **工单类型**：选择 巡检 / 维修 / 送货 / 混合
   - **优先级**：低 / 中 / 高 / 紧急
   - **关联客户**：选择客户
   - **关联资产**：选择具体设备（可选）
   - **联系人/电话**：客户联系人信息
   - **工单描述**：详细描述需求
3. 点击「确定」创建

### 5.3 派单

工单创建后，需要派给具体工程师：

1. 点击工单操作列的「派单」按钮
2. 选择要指派的工程师
3. 点击「确定」

派单后，工单状态变为「待接单」。

### 5.4 接单与处理

**工程师操作**：

1. 在工单列表中看到待接单工单
2. 点击「接单」→ 状态变为「处理中」
3. 到达现场后，点击「打卡」记录到达时间和位置
4. 按工单要求完成任务
5. 点击「完成」→ 状态变为「待确认」

### 5.5 客户确认

客户确认工程师已完成工作后，工单状态变为「已完成」。

### 5.6 工单导出

点击「导出」按钮，可将工单列表导出为 Excel 文件。

## 6. 巡检管理

定期对设备进行巡检，确保设备正常运行。

### 6.1 巡检计划

入口：**巡检管理** → **巡检计划**

管理员配置周期性巡检任务，系统自动按计划生成巡检任务。

**新建巡检计划**：
- 计划名称：如"深圳平安银行 - 例行巡检"
- 巡检频率：每日 / 每周 / 每月 / 自定义
- 关联资产：选择要巡检的设备
- 指派工程师：安排负责的工程师

### 6.2 巡检任务

入口：**巡检管理** → **巡检任务**

系统根据巡检计划自动生成巡检任务。

**执行巡检步骤**：

1. 工程师在任务列表找到自己的巡检任务
2. 点击「执行」开始巡检
3. 到达现场后，点击「打卡」，记录当前位置
4. 按设备逐项检查，拍照记录
5. 每项检查完成后填写结果
6. 点击「完成」，提交巡检结果

**任务状态说明**：

| 状态 | 含义 |
|------|------|
| 待执行 | 任务等待工程师执行 |
| 已到达 | 工程师已到达现场打卡 |
| 进行中 | 巡检进行中 |
| 已完成 | 巡检已完成，提交了结果 |

### 6.3 巡检点管理

入口：**巡检管理** → **巡检点**

为每个资产配置多个检查点，明确检查内容。

**配置巡检点**：
- 巡检点名称：如"A栋1楼配电箱"
- 巡检点编码：唯一编号
- 位置描述：具体位置
- 检查半径：GPS 围栏范围

### 6.4 巡检照片

入口：**巡检管理** → **巡检照片**

查看所有巡检过程中拍摄的照片，按任务和时间筛选。

## 7. 报修申请

客户通过系统提交维修申请。

### 7.1 客户提交报修

入口：**报修申请** → **新增**

> 客户也可通过客户门户提交报修（详见第13节）。

**填写报修信息**：
- 报修标题：简述问题
- 关联客户：选择客户
- 关联资产：选择出现问题的设备（可选）
- 故障描述：详细描述故障情况
- 故障照片：上传故障现场照片（可选）
- 联系人/电话：方便工程师联系
- 期望上门时间：客户希望上门的时间

### 7.2 客服受理报修

客服在「报修申请」列表中处理：

| 操作 | 说明 |
|------|------|
| 受理 | 确认受理报修 |
| 转工单 | 将报修转为正式工单，安排工程师处理 |
| 拒绝 | 拒绝报修并填写原因 |

## 8. 故障记录

记录设备故障情况，方便追溯和统计。

### 8.1 记录故障

入口：**故障记录** → **新增**

**填写内容**：
- 关联资产：选择故障设备
- 关联工单：关联到工单（可选）
- 故障类型：如"电气故障、机械故障、软件故障"
- 故障级别：轻微 / 一般 / 严重 / 紧急
- 故障描述：详细描述故障现象
- 故障时间：故障发生时间

### 8.2 处理故障

| 操作 | 说明 |
|------|------|
| 转工单 | 将故障转为维修工单 |
| 解决 | 标记为已解决，填写解决方案 |
| 验收 | 客户确认故障已解决 |

### 8.3 故障状态

| 状态 | 含义 |
|------|------|
| 已上报 | 故障刚记录，等待处理 |
| 处理中 | 正在处理中 |
| 已解决 | 故障已修复 |
| 已验收 | 客户确认满意 |

## 9. 满意度评价

工单完成后，客户对本次服务进行评价。

### 9.1 提交评价

工单完成后，系统自动生成评价入口，客户可从以下入口进入：

- 工单详情页 → 点击「去评价」按钮
- 客户门户 → 我的评价

**评价内容**：

| 评分项 | 说明 | 评分 |
|--------|------|------|
| 响应速度 | 从报修到工程师到达的速度 | 1-5分 |
| 技术水平 | 工程师解决问题的能力 | 1-5分 |
| 总体评价 | 综合满意度 | 1-5分 |

**附加内容**：
- 填写文字评价（可选）
- 上传附件（可选）

### 9.2 查看评价

入口：**满意度评价**

管理员和客服可查看所有评价记录，了解服务质量。

## 10. 客户用户管理

管理客户账号，客户可用账号登录客户门户。

### 10.1 新增客户用户

入口：**客户用户** → **新增**

**填写内容**：
- 用户姓名
- 所属客户：选择客户公司
- 手机号码：登录账号
- 邮箱（可选）
- 职位（可选）
- 是否主账号：是/否（主账号权限更大）

### 10.2 角色说明

| 角色 | 权限 |
|------|------|
| 管理员 | 可管理本客户的所有工单、资产、报修 |
| 普通用户 | 可查看和提交报修 |
| 只读用户 | 仅可查看，无提交权限 |

## 11. 日报管理

工程师每天提交工作日报，记录当天工作情况。

### 11.1 提交日报

入口：**日报管理** → **新增**

**填写内容**：
- 日报日期：当天日期
- 巡检数量：当天完成的巡检次数
- 工单数量：当天处理的工单数量
- 故障数量：当天处理的故障数量
- 工作总结：当天工作内容总结

> 系统支持 AI 自动生成日报，根据当天工作数据自动填充内容。

### 11.2 自动生成日报

点击「自动生成」按钮，系统根据当天巡检、工单、故障数据自动生成日报初稿，工程师确认后提交。

## 13. 客户门户使用

客户通过独立门户查看和管理自己的工单、资产、巡检记录。

### 13.1 登录客户门户

访问客户门户地址，用客户账号登录。

### 13.2 我的工单

查看自己名下所有工单：
- 查看工单详情（状态、进度、处理记录）
- 对处理中的工单进行「确认完成」操作

### 13.3 我的资产

查看自己公司所有的设备资产：
- 查看资产信息（类型、位置、保修状态）
- 查看资产的巡检历史

### 13.4 提交报修

通过客户门户直接提交报修申请：

1. 点击「提交报修」
2. 填写故障设备、故障描述、上传照片
3. 提交后，客服会受理并转工单

### 13.5 我的巡检

查看自己名下资产的巡检记录和报告。

### 13.6 满意度评价

对已完成的工单进行评价：
- 响应速度评分
- 技术水平评分
- 总体评价
- 文字评价

## 常见问题

### Q1: 忘记登录密码怎么办？
联系系统管理员，管理员可以在后台重置密码。

### Q2: 派单后工程师没有收到通知？
检查「消息通知」是否有新消息，或联系工程师确认。

### Q3: 工单超时了怎么办？
联系管理员调整工单优先级或重新派单。

### Q4: 巡检任务无法完成打卡？
检查手机定位权限是否开启，确保 GPS 定位开启。

### Q5: 客户无法登录客户门户？
确认客户账号已创建且状态为"正常"，联系管理员检查。

### Q6: 如何导出工单/资产数据？
在工单列表或资产列表页面，点击「导出」按钮即可下载 Excel 文件。
